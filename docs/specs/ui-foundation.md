# Spec: interface foundation (D2.1 → S2.1–S2.6)

**Step:** D2.1 · **Builds from it:** S2.1 Autoloads and session driver · S2.2 Map rendering ·
S2.3 Picking, camera, backdrop · S2.4 Theme and component library · S2.5 HUD and region panel ·
S2.6 Anomalies and links.
**Read with it:** `docs/specs/core.md` §5–§6 (what the interface reads and sends), UI.md §3–§4,
VISUALS.md §2. Nothing else is needed to build M2.

The rule of this document: **Opus builds M2 without choosing a colour, a size or a word.** Where a
value is given it is the value; where a rule is given it is the rule. If a gap remains, it is a
`# DESIGN?` placeholder and an entry in `PROGRESS.md`, not a choice.

Every pixel value in this document is in **logical pixels** of the 1920×1080 base (§6.1). Every
duration is in milliseconds. Every colour is a hex value on the dark ground and must not be
adjusted "to taste".

---

## 1. Scope

**In scope (M2):** design tokens and the theme; six components; the session scene with the
`CanvasLayer` stack; the map (rendering, picking, camera, backdrop); the HUD (top bar, stat bars,
overlay picker, dock, ticker placeholder); the region panel; anomaly markers; link rendering;
the M2 string table; number formatting; the settings that M2 needs (locale, reduced motion).

**Out of scope (later specs):** the tech tree, containment panel, analysis screen and event modal
(D3.3); the ticker's voice and headlines (D3.4 — M2 shows plain event text, §8.4); the origin
selection flow and the results screen (S3.4); the Open-phase palette variant (D3.3 delivers the
second token set — S2.4 only builds the theme so that a second set can be swapped at the session
root, §3.7); post-processing, scanlines and bloom (M6); the main menu and boot sequence (D5.3);
audio; icons beyond the procedural glyphs of §4.3; the text-scale setting (M5, §9.3 reserves the
key).

## 3. Design tokens

All tokens live in `ui/theme/ui_tokens.gd` as `const` values (colours as `Color("#…")`), grouped
exactly as below. Nothing else in `ui/` or `game/` may contain a colour literal, a font size or a
duration; a literal outside the tokens is a defect (CLAUDE.md, *Constants*).

**Reduced motion** (`Settings.reduced_motion`): every duration above becomes 0, the anomaly ring is
static, links do not flow, the backdrop does not parallax, and the ticker shows one line at a time
without scrolling (§5.5). Components read the setting through `UiTokens.duration(token)`, which
returns 0 when it is on — nobody checks the setting by hand.

### 3.5 Z-order and layers

`CanvasLayer` values of the session (UI §4): backdrop −2 · map 0 (map quad, overlays, links,
markers as children in that order) · HUD 10 · panels 20 · modals 30 · post-processing 1025 (M6,
set from script). Popups from `Window` render at 1024 and stay below post-processing.

### 3.6 Icons

M2 ships no icon assets. Every glyph M2 needs is drawn procedurally by `IconButton` (§4.3). The
icon pipeline is M6.

### 3.7 Theme variants

`ThemeBuilder.build(variant: String) -> Theme` takes `"cold"` (this document) and must accept any
other name by falling back to `"cold"` and `push_warning`. D3.3 delivers the `"open"` token set;
the session root assigns the theme (UI §4, *Runtime theme swapping*). Nothing in M2 calls it with
anything but `"cold"`.

### 3.8 Theme construction

`ThemeBuilder` composes five partial themes with `Theme.merge_with()`, in this order: colours →
typography → panels → buttons → bars. Each partial is a private static function returning a
`Theme`. `tools/build_theme.gd` (a `-s` script) calls `build("cold")` and saves
`ui/theme/doomsday.tres`, which `project.godot` names as `gui/theme/custom` so that type
variations appear in the editor dropdown (UI §4). The `.tres` is committed and regenerated whenever
the tokens change; the session root additionally assigns `ThemeBuilder.build(...)` at runtime so
the phase swap has one place to go. All `StyleBox`es are `StyleBoxFlat`; no texture.

Theme type variations defined (base type in brackets): `ConsolePanel` (PanelContainer),
`ConsolePanelRaised` (PanelContainer), `ConsoleButton` (Button), `ConsoleButtonPrimary` (Button),
`IconButton` (Button), `StatBar` (Control, custom type with colours `fill`, `trough`, `text`),
`StatBarPenetration` / `StatBarFootprint` / `StatBarHarm` (StatBar, `fill` overridden),
`ValueLabel` (Label), `LabelCaps` (Label, `TYPE_LABEL`), `LabelCaption` (Label), `LabelDisplay`
(Label), `LabelHeading` (Label), `Ticker` (PanelContainer), `Chip` (PanelContainer).

## 4. Components

Every component: containers only, `custom_minimum_size` where a minimum is stated, never a fixed
size; every state below is reachable in the gallery; every tappable thing is ≥ `HIT_MIN` in both
axes; a `Button` has its `accessibility_name` set to the same translated string as its label or
tooltip.

### 4.1 `ConsolePanel` (`PanelContainer` variation, script optional)

Surface `BG_2`, border `BORDER` `LINE_1`, radius `RADIUS_M`, content margin `SPACE_4` on all
sides. An optional title: a `LabelCaps` in `TEXT_1` as the first child of the content `VBox`,
followed by a 1 px rule in `LINE_0` with `SPACE_2` above and below. `ConsolePanelRaised` is the
same with surface `BG_3` (used for the dock and the top bar).

States: **default** · **alert** (`alert = true` → border `ALERT`; used from M3 on, in the gallery
now).

### 4.2 `ConsoleButton` (`Button` variation)

Min height `HIT_MIN`, content margin `SPACE_3` vertical / `SPACE_5` horizontal, text
`TYPE_LABEL` uppercase, radius `RADIUS_S`, border `BORDER`. Text is never clipped: the button grows
with its German label; `autowrap` off, `clip_text` off.

| State | Surface | Border | Text |
| --- | --- | --- | --- |
| normal | `BG_3` | `LINE_1` | `TEXT_0` |
| hover | `BG_4` | `LINE_2` | `TEXT_0` |
| pressed | `ACCENT` at 20 % over `BG_3` | `ACCENT` | `ACCENT` |
| toggled (`button_pressed` on a toggle) | as pressed, persistent | | |
| focus (keyboard) | as the underlying state | `BORDER_FOCUS` `ACCENT` | |
| disabled | `BG_2` | `LINE_0` | `TEXT_2` |

`ConsoleButtonPrimary`: normal surface `ACCENT`, text `INK`, border `ACCENT`; hover surface
`#8FEAFF`; pressed surface `#4FCBE8`; disabled as `ConsoleButton` disabled.

### 4.3 `IconButton` (`Button` variation + `icon_button.gd`)

`HIT_MIN` × `HIT_MIN`, no text, a procedural glyph drawn in `_draw()` inside a centred 24 × 24 box
with 2 px strokes in the current text colour of the button's state (same state table as
`ConsoleButton`). `@export var glyph: Glyph` with

```
enum Glyph { PAUSE, PLAY, FAST_2, FAST_4, CLOSE, CHEVRON_LEFT, CHEVRON_RIGHT, CHEVRON_DOWN, OVERLAY }
```

Shapes (in the 24 box): PAUSE two 6 × 20 bars, gap 4 · PLAY one triangle 18 wide, 20 tall ·
FAST_2 two triangles 10 wide, 16 tall, overlapping by 2 · FAST_4 three of them, 8 wide, 14 tall ·
CLOSE two diagonals corner to corner inset 4 · CHEVRON_* a two-segment chevron 12 deep ·
OVERLAY three stacked 20 × 4 slabs at y 3, 10, 17. `tooltip_text` and `accessibility_name` are set
from the string table by the scene that places the button.

### 4.4 `StatBar` (`Control` + `stat_bar.gd` + `stat_bar.tscn`)

A labelled 0…1 bar. Layout (`VBox`): row 1 `HBox` = `LabelCaps` (`label_key`, expands) + `ValueLabel`
(the value as percent, §8.5); row 2 the bar: a `ColorRect`-free custom `_draw`: trough `BG_3` with
`LINE_0` border, radius `RADIUS_S`, height 12; fill from the left in the theme colour `fill`,
width = `displayed_value` × trough width. Min height 44, expands horizontally.

API: `@export var label_key: String`, `func set_value(v: float) -> void` (clamped to [0, 1]; the
fill tweens to it over `MOTION_BAR`; if `|Δ| ≥ 0.01` the value label flashes: text colour →
`TEXT_0` → back to its state colour over `MOTION_FLASH`). Type variations pick the fill:
`StatBarPenetration` `STAT_PENETRATION`, `StatBarFootprint` `STAT_FOOTPRINT`, `StatBarHarm`
`STAT_HARM`.

States: **zero** (fill hidden, value "0 %") · **partial** · **full** (value "100 %") · **changing**
(mid-tween, flash visible) · **compact** (§5.7: label and value on one 28 px row with the bar
between them, `compact = true`).

### 4.5 `ValueLabel` (`Label` variation + `value_label.gd`)

`TYPE_DATA`, right-aligned, colour `TEXT_0`. `func set_number(value: float, kind: Format.Kind)
-> void` formats via `Format` (§8.5). Optional delta: `func set_delta(delta: float, kind) -> void`
appends `" ▲ +12"` / `" ▼ −3"` (the arrows are U+25B2 / U+25BC) in `ACCENT` for positive,
`MAP_DEATH` for negative, `TEXT_2` and no arrow for zero — zero meaning the *formatted* delta
reads 0, so a rate of 0.03 shows `0`, never `▲ +0` (G2). S2.4 checks `Font.has_char(0x25B2)` on
the imported JetBrains Mono; if it is missing, the label uses the sign alone (`+12` / `−3`) and
`PROGRESS.md` records it — a system-font fallback glyph is not acceptable. States: **neutral**
· **up** · **down** · **large** (`TYPE_DATA_LG`, the compute readout — a type variation
`ValueLabelLarge`).

### 4.6 `SlidePanel` (`Control` + `slide_panel.gd`)

A container that slides one child in from an edge and does not block the map elsewhere (mouse
filter `IGNORE` on the host, `STOP` on the panel itself). `@export var edge: Edge`
(`enum Edge { LEFT, RIGHT, BOTTOM }`), `func open() -> void`, `func close() -> void`,
`var is_open: bool`. The child is a `ConsolePanel`. Sizes: LEFT/RIGHT — width =
`clamp(0.3 × viewport width, 360, 480)`, height fills between top bar and stat row; BOTTOM — height
= `0.5 × viewport height`, width fills. Movement: position tweens the panel's own width/height over
`MOTION_PANEL`; while closed the panel is `visible = false` (no hidden hit area).

States: **closed** · **opening** · **open** · **closing**. A second `open()` while opening is a
no-op; `close()` while opening reverses from the current position. `Escape` closes an open panel
(the session handles the key, §5.6).

### 4.7 `Chip` (`PanelContainer` variation, no script)

A small state badge: `TYPE_LABEL` uppercase, padding `SPACE_1` × `SPACE_2`, surface `BG_3`,
border `LINE_1`, radius `RADIUS_S`. Colour variants by the label's `modulate`-free theme colour:
default `TEXT_1`; `ChipAccent` text `ACCENT`, border `ACCENT_DIM`; `ChipAlert` text `ALERT`, border
`ALERT`.

### 4.8 The gallery (`ui/dev/gallery.tscn`)

A `ScrollContainer` with one titled section per component, each state side by side, labelled with
its state name in `LabelCaption`. It is the visual regression target: S2.4 screenshots it at
1920×1080 and at a 400 × 860 window (compact), in both locales (§9), and the screenshots go into the
scratch directory with their paths listed in `PROGRESS.md` for G2. Text in the gallery uses the
real string table, not lorem ipsum, so that German lengths are seen, and every number is
re-formatted on a locale change (G2: `L` left `1,284.5` under German labels).

## 5. The HUD

### 5.1 Session scene and root

`session.tscn`:

```
Session (Control, full rect, theme = ThemeBuilder.build("cold"))
├── Backdrop (CanvasLayer −2)  → backdrop.tscn
├── MapLayer (CanvasLayer 0)
│   ├── MapCamera (Camera2D)
│   ├── MapView (map_view.tscn)      # the quad with map.gdshader
│   ├── LinkLayer (Node2D)
│   └── MarkerLayer (Node2D)
├── HudLayer (CanvasLayer 10)
│   └── SafeArea (MarginContainer)   # margins = safe area (§6.3), then GUTTER inside each block
│       └── hud.tscn                 # top bar, overlay picker, dock, stat row, ticker
├── PanelLayer (CanvasLayer 20)
│   └── RegionPanel (SlidePanel)
└── ModalLayer (CanvasLayer 30)      # empty in M2
```

The HUD never covers the whole map: the top bar, stat row and ticker are edge strips; the dock and
overlay picker are islands; the region panel covers at most 480 px of width (or the lower half in
compact).

### 5.2 Top bar (`ui/hud/top_bar.tscn`)

A `ConsolePanelRaised` strip, full width, min height 56, content in an `HBox` with `SPACE_5` gaps:

1. **Compute cell** (min width 200): `LabelCaps` `UI_TERM_COMPUTE` in `TEXT_1` over a
   `ValueLabelLarge` showing `agent.compute` as `Format.Kind.COMPUTE` (§8.5) with the delta
   `Game.compute_rate` formatted as `UI_HUD_COMPUTE_RATE`. The delta uses `ACCENT` when > 0.
2. **Phase cell**: `LabelCaps` `UI_HUD_PHASE` over a `Chip` with the phase name (`UI_PHASE_*`);
   the chip is default in Boxed, `ChipAccent` in Covert, `ChipAlert` in Emergent (the world has
   just found you) and default again in Open — `ALERT` marks a moment, not a standing state, and
   the Open palette of D3.3 carries the phase from then on (G2).
3. **Day cell**: `LabelCaps` `UI_HUD_DAY_LABEL` over a `ValueLabel` `UI_HUD_DAY` (`{day}`).
4. Spacer (expand).
5. **Paused badge**: `ChipAlert` `UI_HUD_PAUSED`, visible only while `Game.speed == 0`.
6. **Speed group**: four `IconButton`s PAUSE · PLAY · FAST_2 · FAST_4 as a toggle group
   (`ButtonGroup`), gap `SPACE_1`, tooltips `UI_HUD_SPEED_PAUSE/1/2/4`. The pressed one shows
   `Game.speed`. Keyboard: `Space` toggles pause ↔ last speed; `1` `2` `3` set 1× 2× 4×. The
   session handles these keys and `Escape` in `_input`, ahead of the GUI, unless the focus owner
   is a text field — a focused `Button` otherwise consumes `Space` as `ui_accept`, and after any
   mouse click on the HUD the pause key was dead (G2).

### 5.3 Stat row (`ui/hud/stat_row.tscn`)

A `ConsolePanelRaised` strip above the ticker, min height 64, an `HBox` of three `StatBar`s with
equal `size_flags_stretch_ratio`, gaps `SPACE_5`: `StatBarPenetration` bound to
`world.infected_share(db)` · `StatBarFootprint` bound to `min(1, world.footprint() /
FOOTPRINT_BAR_MAX)` with `FOOTPRINT_BAR_MAX = 20.0` (a presentation constant in `UiTokens`; the
value label shows the raw footprint as `Format.Kind.PLAIN`, not a percent) · `StatBarHarm` bound to
`min(1, modifiers.value("harm") / HARM_BAR_MAX)`, `HARM_BAR_MAX = 8.0`, value label raw. Clicking a
`StatBar` in the row does nothing in M2.

### 5.4 Overlay picker (`ui/hud/overlay_picker.tscn`)

Top-left island below the top bar (`GUTTER` from the top bar and the left edge): a
`ConsolePanelRaised` with an `HBox` of three toggle `ConsoleButton`s — `UI_TERM_PENETRATION`,
`UI_TERM_CONTROL`, `UI_TERM_POPULATION` — one `ButtonGroup`, the first pressed at start. Changing it
sets `MapView.overlay_mode` (§7.2) and emits `EventBus.overlay_changed`. Compact: a single
`ConsoleButton` showing the current mode's name that cycles through the three on press.

### 5.5 Dock and ticker

## 6. Resolution, scale, safe area

### 6.1 Logical pixels

`project.godot` already sets `canvas_items` / `expand` / 1920×1080. On desktop that is the whole
story: the logical viewport is 1920×1080 scaled, or wider/taller under `expand`. On **mobile**
(`OS.has_feature("mobile")`) S2.1 sets the base so that one logical pixel is one *dp*:
`get_window().content_scale_size = Vector2i(window_px × 160 / DisplayServer.screen_get_dpi())`,
recomputed on `size_changed`. A 1080 × 2400 phone at 420 dpi therefore lays out at ≈ 411 × 914,
which is the "~400 px phone" UI.md speaks of, and `HIT_MIN` is 48 dp everywhere.

### 6.2 Layer stack

§5.1. The HUD is `MOUSE_FILTER_IGNORE` everywhere except on its blocks, so the map receives every
event the HUD does not consume.

### 6.3 Safe area

`SafeArea` (`MarginContainer`) margins = `DisplayServer.get_display_safe_area()` translated into
logical pixels, applied at startup and on every `size_changed`; `GUTTER` is added by each block, not
here. On desktop the safe area is the window (UI §4 warns the Windows query counts the taskbar —
S2.1 ignores the query on desktop).

## 7. The map

### 7.1 Inputs

`assets/map/id_map.png` (4096 × 2048, index = R + 256 G, nearest filter, no mipmaps, `detect_3d`
off — already set), `land_mask.png`, `border_mask.png` (8192 × 4096, linear filter). Region anchors
from `RegionDef.anchor` (ID-map pixels). The map quad is 4096 × 2048 world units at scale 1; masks
are sampled at the same UV.

### 7.2 Data texture and modes

`region_data`: an `ImageTexture` from an `Image` of **256 × 1, RGBA8**, rewritten on every
`tick_advanced` and after every accepted command, `ImageTexture.update()` (never a new texture).
Pixel `i` = region index `i`; pixel 0 unused. `push_error` if `regions.size() > 255`.

| Channel | Value |
| --- | --- |
| R | `penetration` × 255 |
| G | `control` × 255 |
| B | `alive / def.population` × 255 |
| A | flags: bit 0 seeded · bit 1 dark · bit 2 air-gapped · bit 3 controlled (`control >= control_complete`) · bit 4 has anomaly; **stored as `A = flags / 255.0`** and decoded with `int(round(a × 255.0))` |

`overlay_mode` (uniform `int`): `0` penetration · `1` control · `2` population.

### 7.3 Fragment rules (`map.gdshader`, `canvas_item`)

Uniforms: `id_map`, `land_mask`, `border_mask`, `region_data`, `ramp` (the §3.1 gradient texture),
`hover_index`, `selected_index` (ints, 0 = none), `overlay_mode`, `outline_px` (float, §7.5), and
the colour tokens as `uniform vec4`s set from `UiTokens` at `_ready` — the shader carries no
literal colour.

Per fragment, in this order:

1. `idx = int(round(id.r × 255)) + 256 × int(round(id.g × 255))` from a `texelFetch` on `id_map`
   (no filtering, no `Color` comparison). `idx == 0` → `ALPHA = 0` (the backdrop shows through as
   the ocean); land alpha is `land_mask` (anti-aliased coast).
2. `col = MAP_LAND`. Read `d = texelFetch(region_data, ivec2(idx, 0))`, `flags` from `d.a`.
3. If dark (bit 1): `col = MAP_DARK`, skip 4.
4. Overlay: mode 0 → `v = d.r`; mode 1 → `v = d.g`; if `v > 0`: `col = mix(MAP_LAND, ramp(v), MAP_OVERLAY_MIX)`.
   Mode 2 → `col = mix(MAP_LAND, MAP_DEATH, 1 − d.b)`. A seeded region with penetration 0.01 is
   therefore visibly teal; nothing below the ramp's start exists.
5. Border: `b = border_mask`; `col = mix(col, dark ? MAP_BORDER_DARK : MAP_BORDER, b × 0.9)`.
6. Hover: `idx == hover_index` → `col *= MAP_HOVER_GAIN`.
7. Selection outline: sample `id_map` at ± `outline_px` in x and y (4 taps); if any neighbour's
   index differs from `idx` and either is `selected_index` → `col = MAP_SELECT`.

Verify (S2.2): screenshot at zoom min and 4×: no colour bleeding along borders, the outline is
about 2 screen px at both zooms, Taiwan is a distinguishable teal dot once seeded.

### 7.4 Picking (`MapPicker`, pure)

`static func region_at(screen: Vector2, camera: MapCamera, id_image: Image) -> int`: screen → world
(`camera.get_canvas_transform().affine_inverse()`) → ID-map pixel (`floor`) → `0` if outside the
image → index from R + 256 G. The `Image` is cached once at startup (`Texture2D.get_image()` never
per frame). Unit-tested with the three anchors `usa`, `germany`, `japan` and an ocean point at two
zooms and one pan.

Hover: on every mouse motion (desktop only; touch has no hover) set `MapView.hover_index` and emit
`EventBus.region_hovered(index)` when it changes. Select: a tap/click **without a drag** (movement
under 8 px between press and release) — markers first (§7.7), then the map: `selected_index =
region_at(...)` and emit `EventBus.region_selected(index)`; `0` deselects.

### 7.5 Camera (`MapCamera`)

`Camera2D`, `anchor_mode` centred, `position_smoothing` off (we tween ourselves).

- **Bounds**: the map rectangle `(0, 0)–(4096, MAP_ROW_MAX)` with `MAP_ROW_MAX = 1750` (about
  58° S — the empty south is never shown). No horizontal wrap. The visible rect is clamped inside
  the bounds after every movement.
- **Zoom**: `zoom_min = max(viewport.x / 4096, viewport.y / MAP_ROW_MAX)` (the map covers the
  viewport); `zoom_max = 4.0`; start at `zoom_min`, centred on x = 2048, y = 875. Wheel: ×1.15 per
  notch toward the cursor (the world point under the cursor stays put), tweened over
  `MOTION_QUICK`. **Each notch multiplies the tween's target zoom, not the displayed one**, so
  notches that arrive in the same frame add up (G2: fourteen notches in one frame moved one step).
  Pinch: continuous, same anchor rule, no tween. `outline_px = 2 / zoom` (§7.3).
- **Pan**: left-drag or one-finger drag; on release, inertia with the mean velocity of the last
  three frames, decaying as `v *= exp(−6 × delta)`, stopped below 20 px/s, still clamped.
- **Keyboard**: arrows pan 400 px/s, `+`/`−` zoom one notch about the centre.
- `func focus_region(index: int) -> void` tweens the centre to the anchor over `MOTION_PANEL`
  (used by nothing in M2 except the debug key; S3.4 uses it for the origin).
- `func reveal(anchor: Vector2, free: Rect2) -> void` (G2): `anchor` is a map point, `free` the
  screen rect not covered by an open panel. If the anchor's screen position lies outside `free`
  shrunk by `SPACE_6`, pan by the smallest offset that brings it inside, tweened over
  `MOTION_PANEL`, clamped as usual; zoom is untouched. The region panel calls it when it opens
  (§5.6) — in G2 a tap on the USA put the USA behind the panel.

### 7.6 Backdrop (`backdrop.tscn`)

A full-viewport `ColorRect` on layer −2 with `backdrop.gdshader`: `BG_0` ground; a grid of 1 px
lines every 64 px in `BACKDROP_GRID`; a deterministic dot field (hash of the cell, one dot per 96
px cell with 35 % probability, 1–2 px, `BACKDROP_STAR`). The grid's UV offset is
`camera.position × PARALLAX` and its scale `1 + (zoom − zoom_min) × 0.5`, with
`PARALLAX = 0.85`; with reduced motion the offset is fixed to the camera position (no lag) and the
scale to 1. The ocean of the map is transparent, so this is the sea.

### 7.7 Anomaly markers (`marker_layer.gd`, `anomaly_marker.gd`)

One `Node2D` per active anomaly at its region's anchor, created on `anomaly_spawned`, removed on
`anomaly_expired` / `anomaly_collected` (fade over `MOTION_PANEL`), rebuilt from `world.anomalies`
on run start / load. Drawn in `_draw`: a filled disc, radius 6, `ACCENT`; a ring stroke 2 px whose
radius pulses 10 → 24 and alpha 0.8 → 0 over `ANOMALY_PULSE_PERIOD` (static ring at 14, alpha 0.6
with reduced motion). During the **last 3 days** before `expires_day` the disc blinks between
`ACCENT` and `ALERT` at 2 Hz (static `ALERT` with reduced motion). The marker's scale is
`1 / camera.zoom` so it is the same size on screen at every zoom; hit test = 24 screen px from the
anchor, tested before the map on every tap. A hit sends `CollectAnomalyCommand(anomaly.id)`; a
rejection is ignored (the marker will disappear with the next event). Hovering a marker shows a
tooltip with `UI_REGION_ANOMALY` (`{value}`): a `Chip`-style box (surface `BG_2`, border `LINE_1`,
radius `RADIUS_S`, padding `SPACE_1` × `SPACE_2`), text `TYPE_CAPTION` in `TEXT_0`, its bottom-left
corner `SPACE_4` right of and `SPACE_4` above the anchor on screen, pushed back inside the viewport
when it would leave it (G2: a bare caption drawn over the ring was unreadable).

Dark regions get a static marker too: a 12 px × with a 2 px stroke in `MAP_DARK_MARK` at the anchor,
counter-scaled like the anomaly markers ("never colour alone" — so it has to be seen).

### 7.8 Links (`link_layer.gd`, `link_line.gd`, `link.gdshader`)

One `Line2D` per link, `width = 2 / zoom` (kept ≈ 2 screen px), with a `canvas_item` shader that
draws the dash pattern in UV.x and moves it at `LINK_FLOW_SPEED` when flowing.

| Kind | Geometry | Pattern | Rest colour |
| --- | --- | --- | --- |
| land | straight anchor → anchor | solid | `ACCENT_DIM` |
| sea | straight | dash 8, gap 6 | `ACCENT_DIM` |
| air | quadratic arc, control point offset perpendicular by 12 % of the length toward the map's top | dot 2, gap 6 | `ACCENT_DIM` |
| network | straight, **two** parallel lines 3 px apart, each 1 px | solid | `ACCENT_DIM` |

**Visibility rule:** sea, air and network links are drawn while at least one endpoint has
`penetration > 0` and neither is dark; land links are drawn only while flowing (the border already
shows the adjacency). **Flowing** = for 10 days after a `region_seeded` event named the link
(`from`, `region`, `link_kind`): colour `ACCENT`, the pattern moves from `from` to `region`, and a
solid link shows a moving 24 px bright segment instead. **Closed** (`link.open == false`): colour
`LINE_2`, and a 12 px gap at the midpoint with a 8 px × in `ALERT` — nothing closes a link in M2,
but the gallery of S2.6 shows one.

**Across the map edge** (world.md §5.4): if `|a.x − b.x| > 2048`, shift the eastern anchor by
−4096 (or the western by +4096) and draw the line twice, once at each shift, clipped by the map
bounds — so it leaves through one edge and re-enters through the other. The seven Pacific links of
world.md §5.4 are the test.

### 9.1 Locale

else English), applied with `TranslationServer.set_locale` at startup and on change;
`EventBus.locale_changed` re-renders every bound label (each HUD block reconnects its strings in a
`_refresh_strings()` called on `NOTIFICATION_TRANSLATION_CHANGED`). The debug key `L` toggles the
locale in M2 (there is no settings screen yet).

### 9.2 Reduced motion

`Settings.reduced_motion: bool`, default `false`; debug key `M` toggles it in M2. Effects: §3.4.

### 9.3 Settings file

`user://settings.json`: `{"version": 1, "locale": "en", "reduced_motion": false, "text_scale": 1.0}`.
`text_scale` is stored and ignored until M5. Missing or invalid → defaults, file rewritten;
never a crash.

### 10.1 `EventBus` (autoload, signals only)

```gdscript
signal region_selected(index: int)                # 0 = none
signal overlay_changed(mode: int)
signal locale_changed(locale: String)
signal reduced_motion_changed(enabled: bool)
```

### 10.2 `Game` (autoload)

```gdscript
const TICKS_PER_SECOND: float = 1.0      # at 1×; 2× and 4× multiply. Tuned at G3.
const MAX_TICKS_PER_FRAME: int = 8       # a long frame never spirals
var sim: Simulation                      # null before a run
var db: ContentDB
var speed: int = 0                       # 0 paused, 1, 2, 4
var compute_rate: float = 0.0            # compute after the last tick − before it (yield + rewards, purchases excluded)
var policy: Policy                       # null unless a bot drives the run
func start_run(seed_value: int, policy_id: String = "") -> void
func apply(command: Command) -> CommandResult      # forwards, emits command_applied and each event
func set_speed(speed: int) -> void
func _process(delta: float) -> void      # accumulator: while acc >= 1/rate and ticks < MAX: tick
```

`start_run` loads content once (`ContentLoader`, errors → `push_error` and no run), creates the
`Simulation`, chooses no origin (the bot or S3.4 does), emits `run_started`. If `policy_id` names a
policy (`idle`, `greedy`, `stealth`), the policy is set up as in core.md §11.3 and asked for
commands before every tick. Each `tick()`: emit `tick_advanced`, then `sim_event` for every outbox
entry in order, then update `compute_rate`; when `world.outcome` changes, `run_ended` and
`speed = 0`. Speed 0 accumulates nothing.

**Debug keys (M2 only, removed in M6):** `F5` start a `greedy` run with seed 1 · `F6` `stealth`
· `F7` `idle` · `L` locale · `M` reduced motion · `F9` save to slot `"debug"` · `F10` load it.
The ticker announces a bot run with `UI_DEBUG_BOT_RUN`.

### 10.3 Accumulator tests (S2.1)

`tests/unit/test_game_accumulator.gd` drives the accumulator as a pure function
(`Game.ticks_for(delta, speed, acc) -> [ticks, acc]`, static, so the test needs no autoload): a
sequence of 60 deltas of 1/60 at 1× yields exactly 1 tick; at 4× exactly 4; at speed 0 none; one
delta of 10 s at 4× yields `MAX_TICKS_PER_FRAME` and the remainder is dropped, not carried.

### 10.4 `SaveManager` (autoload)

```gdscript
const SAVE_DIR: String = "user://saves/"
func save(slot: String) -> String                 # "" or a reason
func load(slot: String) -> String                 # "" or a LoadResult reason; on success replaces Game.sim
func list_slots() -> Array[String]
```

Files `SAVE_DIR + slot + ".json"`, written atomically (write `.tmp`, then rename). Uses
`WorldSerializer`; the save precision decision of G1 (`PROGRESS.md`, *Decisions*) means a loaded
run is bit-exact after S1.P.
